## Contenidos principales del módulo
UT1. Introducción a los lenguajes de marcas
UT2. XML: sintaxis, estructura y espacios de nombres
UT3. Validación con DTD y XML Schema
UT4. XPath: consulta y navegación de documentos
UT5. XSLT: transformación de documentos
UT6. Sindicación de contenidos: RSS y Atom
UT7. Almacenamiento, formatos de intercambio y XQuery
UT8. Sistemas empresariales: ERP y CRM
UT9. HTML5: estructura, semántica y accesibilidad
UT10. CSS: presentación y diseño adaptable
UT11. JavaScript y manipulación del DOM
